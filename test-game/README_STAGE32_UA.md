# Етап 32 — отримані збірки CI та тестова інтеграція

29 вересня 2026. Це тестова копія гри 5.12.4, не оновлення чинного сайту.

Збірка GitHub Actions №2, commit ce5b46bf93f07c7dea6793e9698df75ced332cad,
run ID 36526648614. Успішні обидва завдання; оригінальні архіви збережені
окремо у контрольному пакеті. Вкладений plentychess-ci-source.zip містить
відповідні вихідні коди обох конфігурацій; LICENSE у пакеті рушія — GPLv3.

У грі встановлено baseline/material-center-v1. Candidate/handcrafted-tapered-v1
залишається окремою експериментальною збіркою. Її перевага за силою не доведена.
Журнал гри тепер записує справжню назву оцінювача, отриману від WASM.
Додано перевірку очікуваної оцінки, щоб не приймати випадково змішані збірки.
Автоматичне визнання поразки за сирою оцінкою PlentyChess не ввімкнене.

Перевірено локально: усі 8 SHA256-записів кожного архіву; по 26 реальних
WASM-пошуків для кожного рушія (повтори, аварійний вихід, відновлення після
некоректного вводу). Окрема перевірка легальності зі сторонніми JS-правилами
запускається скриптом verification/check_received.cjs у контрольному пакеті.

Повторний локальний тест у Chromium заблоковано відсутністю браузера:
завантаження повернуло непридатний ZIP. Це не результат тесту гри.
CI виконав власні браузерні тести рушія, але новий повний інтерфейс гри
ще потребує браузерного тестування, а також перевірки на справжньому iPhone.
Статична перевірка синтаксису JavaScript інтерфейсу пройдена.

НЕ публікувати поверх index.html чинного сайту до повного тестування.
Не видаляти існуючий coi-serviceworker.js на сайті. Ця копія, як і попередня,
не містить його; він потрібен на хостингу для наявних багатопотокових рушіїв.

Наступне:
1. Браузерні перевірки інтерфейсу: ходи, історія, скасування, помилки,
   партії рушій–рушій, мат/пат, самотній король без автоматичної поразки.
2. Перевірити Safari на iPhone; лише потім готувати публікацію.
3. Порівняти baseline/candidate за однакових бюджетів пошуку.
4. Дослідити неможливість мату за БУДЬ-ЯКОЇ легальної послідовності для
   наборів фігур у всіх 4 варіантах × 2 розмірах. Узгодити таблицю з користувачем
   до автоматичного застосування нічиїх для людей і програм.
   Неможливість форсувати мат не дорівнює теоретичній неможливості мату.
