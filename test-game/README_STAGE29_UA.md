# Тестова гра 5.12.3 — матчі з PlentyChess

Відкрити через HTTP(S), вибрати режим «Програма проти програми» та
незалежно обрати рушій червоних і зелених. Є Fairy-Stockfish, Reckless,
PlentyChess, також матч рушія із самим собою. Зміна учасника створює
нову партію. Пауза зупиняє розрахунок і годинник; відновлення продовжує
поточну позицію. Зміна рівня діє з наступного ходу.

Це окрема НЕОПУБЛІКОВАНА тестова копія. Plenty експериментальний, без
адаптованої NNUE; рівні — бюджети пошуку, не перевірений рейтинг сили.
Safari на iPhone ще не перевірено. Не запускати з file:// і не видаляти
наявний coi-serviceworker.js при подальшому встановленні на хостинг.

Перевірено: 9 матчів/771 півхід, завершення матом, пауза/відновлення,
прострочений годинник, помилка мережі без підміни рушія, закінчення та
спеціальні ходи. Гарантованих нічиїх за матеріалом ще не додано.

Повний код і тести: plentychess-source-stage29.zip, звіт
README_CAPABLANCA_STAGE29_UA.md та партії verification/STAGE29_DUELS.json.
Старі README/VERIFICATION/SHA256SUMS і source-stage28 у папці залишені
як історія основи; вони не засвідчують нову сторінку. Цей README актуальний.
