# Тестова версія 5.12.2 — PlentyChess, етап 28

Це окрема експериментальна копія, не опубліковане оновлення.
У налаштуваннях суперника з'явився PlentyChess. Вибрати його й почати
нову партію. У матчах програм поки залишаються Fairy-Stockfish/Reckless.

Потрібне відкриття через HTTP(S); безпосередньо з «Файлів» iPhone гра
з WASM не запускається належним чином. На чинному хостингу зберегти
coi-serviceworker.js: цього файла немає в попередньому архіві-основі.
Не замінювати чинну гру без окремої перевірки на iPhone Safari.

Plenty використовує оригінальний пошук, але тимчасову оцінку без NNUE.
Рівні 1–48 задають бюджети, а не відкалібровану силу чи Elo.
Автоздача Plenty за його сирою оцінкою навмисно не ввімкнена.
Самотній король не означає автоматичної поразки. Нових правил
гарантованої нічиєї за складом фігур ще немає.

Перевірено у Chromium: усі 8 комбінацій дошки та правил, ходи Plenty,
історію, скасування новою партією; Fairy і Reckless теж роблять ходи.
Це не заміняє випробування Safari та довгих партій.

Повний код Plenty й рецепти збирання: plentychess-source-stage28.zip.
Інші README/VERIFICATION/SHA256SUMS у цій папці успадковані від базової
версії 5.12.1; вони не описують і не засвідчують новий index.html.
Актуальний звіт етапу — README_CAPABLANCA_STAGE28_UA.md у коді Plenty.
